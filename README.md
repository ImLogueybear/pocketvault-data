# pocketvault-data

Prebuilt, public data for the [Pocket Vault](https://github.com/ImLogueybear/PocketVault) card scanner.

- `scan/` — the offline card-recognition index: one compact `int8` shard per set
  plus `scan/index.json`. The app downloads a shard (~100 KB per set) instead of
  fetching and fingerprinting every card image on-device.
- `updates.json` — the public update manifest the app polls for new versions.

Both are generated by the PocketVault repo and published automatically by its
**Publish scan index** and **Publish update manifest** workflows.

Served from GitHub Pages: https://imlogueybear.github.io/pocketvault-data/

Do not edit files here by hand — they are overwritten on each publish. Never
commit build artifacts (such as APKs) here: published files are public.
